
## 📌 Overview

This repository serves as a compilation of laboratory activities, programming exercises, and problem-solving tasks completed for **CPE010 – Data Structures and Algorithms**. It showcases the practical application of concepts, programming techniques, and algorithms discussed throughout the course using **C++**.
